## 1. How to View the Presentation

This presentation deck is completely self-contained with no external runtime dependencies. The official GreenSock Animation Platform library (`gsap.min.js` v3.15.1) is bundled locally in `vendor/gsap.min.js`.

### Quick Start:
1. Simply double-click `index.html` to open it in any modern browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).
2. Alternatively, serve via Python's built-in HTTP server:
   ```bash
   python -m http.server 8000
   ```
   and navigate to `http://localhost:8000/presentation/`.
